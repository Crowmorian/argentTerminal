# Local typefaces

These fonts are served locally; the site does not contact Google Fonts.

- Barlow Condensed SemiBold: https://fonts.google.com/specimen/Barlow+Condensed
- Cinzel SemiBold: https://fonts.google.com/specimen/Cinzel
- IBM Plex Mono Regular: https://fonts.google.com/specimen/IBM+Plex+Mono

The accompanying OFL files contain each font's SIL Open Font License. WOFF2 files were obtained from the Google Fonts stylesheet API for the Latin character set.
