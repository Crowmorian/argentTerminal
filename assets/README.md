# Visual reference

`slayer-rune.png` is a local copy of the DOOM Eternal icon hosted by SteamGridDB:

- Source: https://www.steamgriddb.com/icon/2679
- Image: https://cdn2.steamgriddb.com/file/sgdb-cdn/icon/9813b270ed0288e7c0388f0fd4ec68f5/32/512x512.png

The Slayer mark is used as a decorative emblem for this unofficial fan-made puzzle. It is not presented as a Sentinel credential or a canonical access mechanism. DOOM belongs to id Software / Bethesda.

Lore and visual context: https://doom.bethesda.net/ and the in-game Sentinel codex entries. The access-key authorities, command order, and accompanying decrees are original puzzle fiction using that setting; they are not purported quotations from the games.
